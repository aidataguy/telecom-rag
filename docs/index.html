// rag pipeline
01 User query → embed with nomic-embed-text → 768-dim vector
02 ChromaDB cosine similarity search → top-K incident reports + runbooks
03 Distance threshold filter → only chunks with score < 0.7 pass
04 Build prompt with context → send to Mistral 7B on Windows GPU
05 Stream tokens back → FastAPI StreamingResponse → client
